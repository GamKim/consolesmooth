# 비교 영상과 설정 창 사진

ConsoleSmooth 1.0.1 소개 글에 쓴 영상입니다. 이 페이지에서 바로 재생됩니다(10MB 이하로 줄인 사본). 영상 아래 "원래 화질 파일"은 원본입니다.

측정 환경: RTX 5080, AVerMedia GC573, 160Hz 모니터, Streaming Center. [English](README.en.md)

## 화질 비교 (왼쪽 원본, 오른쪽 생성 켬, 반속)

Streaming Center 녹화(생성 프레임 포함)를 나란히 붙이고, 사이트 재생이 60fps까지라 반속으로 만들었습니다. 30fps 보정은 1.0.1에서 기본 꺼짐입니다.
