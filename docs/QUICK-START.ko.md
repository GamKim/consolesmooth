# ConsoleSmooth 5분 시작 (GTA6 · Switch 2)

[English](QUICK-START.en.md) · [자세한 사용법](GUIDE.ko.md)

AVerMedia 캡처보드와 **Streaming Center**를 이미 쓰고 있다면 프로그램을 더 깔지 않아도 돼요. 플러그인 하나만 설치하면 PS5 GTA6 30fps를 60fps로, Switch 2 60fps를 120fps로 볼 수 있어요.

## 맞는지 먼저 확인

| 항목 | 조건 |
|---|---|
| 캡처보드 | AVerMedia. 확인한 카드: GC573, GC313 Pro, GC553 Pro. GC553G2는 아직 직접 확인하지 않았어요(같은 Streaming Center를 쓰니 동작할 가능성이 높아요). |
| 프로그램 | AVerMedia Streaming Center 1.8.22.2 또는 1.9.19.1. OBS·RECentral에서는 동작하지 않아요. |
| 그래픽카드 | 최소 AMD RX 6600 · 지포스 RTX 2060급(FSR 3) / RTX 3070·4060급(RIFE). NVIDIA VFG는 RTX 40/50. |
| 모니터 | 120Hz 이상 |

## 설치하고 켜기

1. [Releases](https://github.com/GamKim/consolesmooth/releases/latest)에서 `ConsoleSmooth-Plugin-Setup-<버전>.exe`를 받아요. 서명이 없는 파일이라 경고가 뜨면 **추가 정보 → 실행**을 누르세요.
2. Streaming Center를 **완전히 끄고**(트레이 아이콘까지) 설치 파일에서 **설치**를 눌러요.
3. Streaming Center를 켜고 게임 화면이 들어오면 툴바의 **프레임 생성 설정** → **권장 설정** → **적용**을 눌러요. 약 25초 동안 이 PC에서 실제로 시험해 보고 설정을 골라 줘요.
4. **프레임 생성 켜기** 버튼이나 **Ctrl+Alt+F**로 켜요. 끌 때도 같은 키를 누르면 돼요.

## 게임별 추천

| 게임 | 배수 | 메모 |
|---|---|---|
| PS5 GTA6 (30fps) | **2배** → 60 | 3배·4배(→90·120)도 되지만 지연과 깨짐이 늘어요. 처음에는 2배를 권해요. **GTA6을 할 때는 Streaming Center의 소스 편집에서 입력을 30 FPS로 설정하는 것을 권장해요.** |
| Switch 2 (60fps) | **2배** → 120 | 120Hz 모니터에 맞아요. |
| 격투·리듬·FPS·경쟁 게임 | 쓰지 않기 | 화면이 원본보다 늦게 보여서 판정이 중요한 게임에는 맞지 않아요. |

- 지연을 가장 줄이려면 **프레임 생성** 탭 → 표시 방식에서 **전체 화면**을 고르세요. 저지연 보기가 자동으로 같이 켜지고, 다른 창을 눌러도 전체 화면은 닫히지 않아요. 개발자 측정으로 원본보다 약 9~19ms 늦게 보였어요(RTX 5080 기준).
- 녹화·방송에 생성된 프레임을 넣으려면 **표시 · 녹화** 탭의 녹화 원본을 **생성 프레임 포함**으로 바꾸세요.
- 설정 창 맨 아래 상태 줄에 지금 생성 fps와 원본이 도착해서 화면에 나오기까지 걸린 시간(프로그램 안에서 잰 값)이 나와요.

문제가 있으면 [자세한 사용법의 문제 해결](GUIDE.ko.md#문제-해결)을 봐 주세요.
