# ConsoleSmooth 측정 방법

[English](MEASUREMENT.md) · [README로 돌아가기](../README.ko.md)

ConsoleSmooth 문서와 결과 페이지의 숫자를 어떻게 쟀는지 적었어요. 모두 **개발자 한 명이 한 PC에서 잰 자체 측정**이에요. 같은 방법으로 누구나 다시 잴 수 있게 하는 것이 목적이에요. 숫자를 인용할 때는 날짜와 버전을 같이 적어 주세요.

## 공식 배포 위치

- 설치 파일은 **[github.com/GamKim/consolesmooth/releases](https://github.com/GamKim/consolesmooth/releases)** 에서만 배포해요. 다른 사이트나 재업로드 파일은 공식 파일이 아니에요.
- 설치 파일은 코드 서명이 없어요. 받은 뒤 같은 릴리스의 `SHA256SUMS-<버전>.txt` 값과 비교해 주세요.

  ```powershell
  Get-FileHash .\ConsoleSmooth-Plugin-Setup-<버전>.exe
  ```

## 측정 PC

| 항목 | 내용 |
|---|---|
| 그래픽카드 | NVIDIA RTX 5080 (다른 등급은 클럭을 고정해 흉내 낸 값이고 근사치예요) |
| 캡처보드 | AVerMedia GC573 (Live Gamer 4K) |
| 프로그램 | AVerMedia Streaming Center 1.9.19.1 |
| 콘솔 | Switch 2(60fps 게임), PS5(GTA6 등 30fps 게임) |

## 1. 지연: 휴대폰 240fps 촬영

1. 캡처보드의 패스스루 출력을 연결한 **패스스루 모니터**(PC를 거치지 않은 원래 화면)와 **PC 모니터**를 나란히 놓아요.
2. 두 화면을 휴대폰 240fps 슬로 모션으로 한 화면에 담아 찍어요.
3. 장면은 밝은 움직임이 분명한 순간을 써요(Switch 2 젤다의 검 휘두르기, GTA6는 일시 정지 메뉴 열고 닫기).
4. 영상에서 두 화면의 밝기 변화 신호를 뽑고 서로 맞춰서(교차 상관) 몇 ms 늦게 바뀌는지 구해요. 휘두르기 한 번마다 따로 계산해서 평균을 내요.
5. 결과는 **패스스루보다 몇 ms 늦게 보이는가**예요. 캡처보드·Streaming Center·생성·모니터 지연이 모두 들어간 값이에요.

같은 방법으로 Streaming Center 기본 미리보기(생성 끔), 다른 프로그램의 실제 출력도 재요. 다른 프로그램은 배포된 그대로, 권장 설정으로 쓰고 ConsoleSmooth 쪽에 맞추어 낮추지 않아요.

## 2. 앱 안 지연 표시

설정 창 맨 아래 상태 줄의 `원본→화면 X ms`는 원본 프레임이 플러그인에 들어온 순간부터 화면 표시 요청(Present)이 끝날 때까지를 2초마다 평균한 값이에요.

- 캡처보드, Streaming Center가 플러그인에 넘기기 전까지의 시간, 모니터 지연은 **들어 있지 않아요.** 그래서 1번(휴대폰)보다 항상 작아요.
- 저지연 보기 + 전체 화면(빠른 방식)에서만 나와요.
- 같은 PC에서 설정을 바꿔 가며 비교하는 용도예요. 다른 프로그램의 종단 지연과 직접 비교하는 숫자가 아니에요.

## 3. 화질: 같은 입력에서 PSNR

1. 60fps 게임 화면을 **무손실**로 녹화해요(캡처 장치에서 직접 utvideo, 또는 OBS "무손실").
2. 짝수 번째 프레임만 입력으로 넣고, 홀수 번째 프레임(실제 화면)을 정답으로 써요.
3. 생성된 프레임과 정답의 PSNR을 구해요. 화면 전체, 움직임이 있는 곳, HUD 영역, 가장 나쁜 5%를 따로 봐요.
4. 다른 프로그램도 같은 파일을 넣고 **실제로 내보낸 결과**를 채점해요.

## 4. GPU 사용량

- `nvidia-smi`를 100ms 간격으로 기록해서 사용률(%)과 전력(W)의 평균을 내요.
- Streaming Center만 켠 상태를 먼저 재고, 생성을 켰을 때 늘어난 양을 봐요.

## 5. 생성 프레임 수와 빠진 장

- 10초마다 남는 로그(`GPU_VIEW shown_orig / shown_gen / dropped`)로 원본 몇 장, 만든 장 몇 장이 실제로 화면에 나왔는지 세요.
- 화면 녹화(ddagrab 4K)로 같은 장면이 두 번 나온 프레임을 세서 확인해요.

## 한계

- PC 한 대, 그래픽카드 한 종류, 장면 몇 개만 썼어요.
- 다른 등급 그래픽카드는 RTX 5080의 클럭을 낮춰 흉내 낸 값이라 메모리 속도가 달라요. 실제 카드보다 좋게 나올 수 있어요.
- 다른 프로그램은 측정 당시 버전이에요. 업데이트 후에는 결과가 달라질 수 있어요.
