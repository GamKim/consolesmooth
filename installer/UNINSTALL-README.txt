ConsoleSmooth 제거 방법

1. Streaming Center를 닫습니다.
2. 파일 탐색기에서 Streaming Center 설치 폴더 안의 Plugin\ConsoleSmooth 폴더를 엽니다.
   기본 위치: C:\Program Files (x86)\AVerMedia\AVerMedia Streaming Center\Plugin\ConsoleSmooth
3. Uninstall.exe를 실행하고 "제거"를 누릅니다. 관리자 권한을 물으면 "예"를 누릅니다.
4. "제거가 완료되었습니다"가 나오면 끝입니다. 다음에 Streaming Center를 켜면 원래 상태로 돌아갑니다.

지워지는 것
- 이 설치 프로그램이 넣은 파일(플러그인, 엔진, 모델, 안내 파일).
- 사용자 환경 변수 GST_TRACERS의 consolesmooth 값. 원래 있던 다른 값은 그대로 둡니다.

남는 것
- Streaming Center 원본.
- ConsoleSmooth 설정: %LOCALAPPDATA%\ConsoleSmoothNative
- 직접 바꾼 파일, 제거 프로그램 자신.
- 남은 Plugin\ConsoleSmooth 폴더와 설정 폴더는 직접 지워도 됩니다.

주의
- Streaming Center 폴더 전체나 다른 플러그인 폴더는 지우지 마세요.
- Streaming Center를 먼저 제거하거나 다시 설치하면 플러그인 폴더가 남을 수 있습니다. 이때도 남은 Plugin\ConsoleSmooth 폴더의 Uninstall.exe로 지우거나 폴더를 직접 지우면 됩니다.
- 제거 중 "변경된 파일"이 있다고 나오면, 직접 바꾼 파일은 남겨 두고 나머지만 지운 것입니다.
