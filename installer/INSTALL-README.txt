ConsoleSmooth 1.0.1 — AVerMedia Streaming Center용 프레임 생성 플러그인

AVerMedia와 관계없는 비공식·무료 플러그인입니다.
캡처보드로 들어온 콘솔 화면(예: 60fps)에 중간 프레임을 만들어 넣어 Streaming Center 미리보기를 더 부드럽게 보여 줍니다(예: 120·160fps).
플레이는 Streaming Center 미리보기를 보면서 합니다. 모니터 직결(패스스루)보다 늦게 나오므로 대전·리듬 게임은 권장하지 않습니다.

필요한 것
- AVerMedia 캡처보드와 AVerMedia Streaming Center(확인한 버전 1.8.22.2, 최신 1.9.19.1 x64). 확인한 캡처보드: Live Gamer 4K(GC573), GC313 Pro, GC553 Pro.
- Vulkan을 지원하는 그래픽카드. 최소 사양: AMD Radeon RX 6600(FHD 60fps → 120fps). 실제 카드로 확인한 가장 낮은 GPU입니다.
  지포스는 RTX 5080 클럭을 낮춘 근사 측정으로 RTX 2060급에서 RIFE 95.5%, FSR 3 99.2%를 생성했습니다.
  RX 6600에서는 RIFE 4.6이 움직임을 1/4 크기로 계산하고(화질 조금 낮음), FSR 3은 "GPU 클럭 유지"를 켜야 합니다(AMD는 기본 켬).
  이보다 낮은 GPU는 지원하지 않습니다. 켜질 수는 있지만 생성이 모자라거나 화질이 떨어집니다.
- 생성된 프레임을 보려면 120Hz 이상 모니터.

설치
1. Streaming Center를 설치하고 종료합니다.
2. ConsoleSmooth-Plugin-Setup-1.0.1.exe에서 설치(또는 업데이트)를 누릅니다. 설치 위치에 따라 관리자 권한을 요청합니다.
   서명이 없는 설치 파일이라 Windows SmartScreen 경고가 나오면 "추가 정보 → 실행"을 누릅니다.
   설치하면 사용자 환경 변수 GST_TRACERS에 "consolesmooth"를 더합니다. Streaming Center 1.9.19.1부터는 이 설정으로 플러그인이 켜집니다.
   다른 프로그램에는 영향이 없고, 제거하면 이 값도 지웁니다(원래 있던 값은 그대로 둡니다).
3. 완료 후 원래 Streaming Center 아이콘으로 실행합니다.
4. 툴바에 "프레임 생성 켜기"와 "프레임 생성 설정" 버튼이 생깁니다. "프레임 생성 켜기"를 누르면 켜집니다(처음에는 꺼져 있음).
   설정 창은 "프레임 생성 설정" 버튼으로 엽니다.

설정 창 (탭 3개)
프레임 생성
- 입력 프레임은 캡처보드에서 자동으로 감지합니다. PS5처럼 "60Hz"가 실제로 59.94Hz인 입력도 지원합니다(목표 fps도 같은 비율로 맞춤: 160 → 159.84).
- 모델: RIFE 4.6(기본, 화질 우선) 또는 FSR 3(2배·4배, 가벼움. 4배는 가운데 장면을 두 번 나눠 만듭니다).
- 출력: 2~4배 또는 목표 프레임. 처리 해상도는 Streaming Center 녹화 설정 해상도를 따릅니다. FHD(1920×1080)를 권장합니다.
- 배수는 입력 신호 기준입니다. 30fps 게임도 콘솔은 60Hz로 보내므로, 2배면 출력은 120Hz입니다. 그 안에 새 화면이 몇 장 들어가는지는
  30fps 보정이 정합니다(아래 "30fps 게임" 참고).
- 지연 설정: 낮은 지연(생성 버퍼 15~25ms, 기본 15ms) 또는 안정 우선(자동/50/100/150ms). 버퍼가 클수록 지연이 늘어납니다.
  낮은 지연에서는 실제 처리 시간에 맞춰 버퍼를 자동으로 조금 늘렸다가, 안정되면 다시 줄입니다.
- 지연 우선(기본 끔, RIFE 전용): RIFE 움직임을 1/4 크기로 계산해 버퍼를 조금 더 줄입니다. 화질은 약 0.9dB 낮아집니다.
- 표시 방식: 창(기본) 또는 전체 화면(Esc로 복귀). 전체 화면은 화면 표시 단계가 줄어 지연이 짧습니다.
- 저지연 보기(베타, 기본 끔): 전체 화면으로 들어온 화면을 바로 보여 줍니다(생성을 꺼도 동작). 켜 두면 녹화·방송에는 화면이 들어가지 않습니다.
- 권장 설정: 약 25초 동안 RIFE와 FSR 3로 실제 생성을 시험해 보고 모델·배수를 추천합니다.
표시·녹화
- 녹화 소스를 "생성 프레임 포함"으로 녹화할 때는 Streaming Center 설정 → 녹화 설정 → 동영상 비트율을 40000~50000으로 올리세요. 120fps를 15000(기본)으로 녹화하면 화면이 뭉개집니다.
- 프레임 표시: 화면에 기본으로 "입력 / 지금 fps"(캡처 신호 / 1초에 화면에 낸 장)를 보여 줍니다. "게임 실제 프레임으로 표시"를 켜면 "원본 / 지금 fps"(예: 30 / 60 fps)로 바뀝니다. 원본 = 게임이 1초에 바꾼 화면 수,
  지금 = 원본 + 생성한 장. 화면이 멈춰 있으면 0 / 0이 됩니다. 켠 직후 약 2초는 신호/출력 fps가 보입니다.
- 표시 위치, 녹화 소스(원본 또는 생성 프레임 포함, 다음 녹화부터).
- 전체 화면 선명하게(기본 끔): 전체 화면에서 단순 확대 대신 선명한 확대와 선명화를 씁니다.
고급
- 30fps 보정(기본 끔): 30fps 게임을 "게임 fps × 배수"로 고르게 만듭니다(아래 "30fps 게임" 참고). 지연 약 +8ms.
- HUD 보호(기본 켬): 체력바·지도·버튼 표시처럼 화면에 고정된 요소를 원본 그대로 써서 떨림을 줄입니다. 반투명 HUD도 포함합니다.
  캐릭터가 화면 가운데에 오래 서 있는 3인칭 게임(GTA 등)에서는 캐릭터를 HUD로 보고 머리카락 끝이 깨져 보일 수 있습니다. 그럴 때는 끄세요.
  반투명 글자 창(도움말·메뉴)이나 게임 속 웹페이지가 움직일 때 글자가 깨져 보여도 끄세요.
- GPU 클럭 유지(AMD는 기본 켬): 생성 중 GPU가 클럭을 낮추지 않게 합니다.
- FSR 3 가속(기본 끔), 진단 정보 내보내기(문제가 있을 때 눌러 저장한 파일을 보내 주세요. 장비·설정·최근 기록을 텍스트 파일 하나로 저장, 자동 전송 없음).

30fps 게임 (예: PS5 GTA5 화질 모드, 블러드본)
- 콘솔은 같은 화면을 두 번씩 60Hz로 보냅니다. 화면 숫자는 "30 / …"으로 나옵니다.
- 30fps 보정 끔, 2배: 새 화면 60장. 지연은 가장 적지만 새 화면 간격이 약 8ms와 25ms로 번갈아 고르지 않습니다.
- 30fps 보정 켬, 2배: 새 화면 60장을 16.7ms마다 고르게(30 → 60). 3배는 90, 4배는 120.
  가운데 장을 만들려면 다음 원본(33ms 뒤)을 기다려야 해서 생성 버퍼가 약 8ms 늘어납니다(측정: 25.0 → 33.4ms).
- 녹화(생성 프레임 포함)도 같습니다. 파일은 출력 fps(60Hz × 2배 = 120fps)로 저장되지만, 30fps 게임이면 그중 새 화면은 60장이고 나머지는 같은 화면이 한 번 더 들어갑니다(측정: 파일 119.9fps, 새 화면 60/초).
- 원본 사이 움직임이 60fps 게임의 두 배라, 고개를 갑자기 돌릴 때 얼굴처럼 세밀한 부분이 일렁일 수 있습니다(생성 모델의 한계).

언어
Streaming Center 언어를 따릅니다(한국어 Streaming Center → 한국어, 그 밖에는 영어).

한계
- 아주 빠른 카메라 회전에서 배경이 조금 일렁일 수 있습니다(생성 모델의 한계).
- 빠른 배경 위 글자·지도는 HUD 보호로 줄였지만 완전히 없지는 않습니다. 아주 흐린 아이콘은 잡지 못할 수 있습니다.
- HDR·10비트, 8K는 지원하지 않습니다. 입력은 30~120fps(29.97·59.94·119.88 포함)를 받습니다. PS5 등에서는 HDR을 꺼 주세요.
- 4K 처리: RTX 5080 엔진 측정에서 RIFE 2배까지 들어갑니다(움직임 1/4 크기 자동, 1장 약 14ms). 3배 이상은 모자랍니다. 보통은 녹화 설정 해상도를 1920×1080으로 두는 것을 권장합니다.
- GPU가 느리면 목표 프레임에 미달하거나 이전 프레임이 반복될 수 있습니다. 많이 모자라면 생성을 멈추고 원래 속도로 돌아갑니다.

파일 위치
플러그인: <Streaming Center>\Plugin\ConsoleSmooth\
사용자 설정: %LOCALAPPDATA%\ConsoleSmoothNative\settings.ini
기존 앱 파일과 바로가기는 바꾸지 않습니다.

제거
Streaming Center를 종료하고 플러그인 폴더의 Uninstall.exe를 실행합니다.
원본 앱, 사용자 설정, 사용자가 바꾼 파일은 남겨 둡니다. 남은 ConsoleSmooth 폴더는 직접 지워도 됩니다.
Streaming Center 폴더 전체나 다른 플러그인 폴더는 지우지 마세요.

호환성
확인한 환경: Windows x64, Streaming Center 1.8.22.2·1.9.19.1, GC573·GC313 Pro·GC553 Pro, RTX 5080, RX 6600.
AVerMedia 정식 서명이 있는 다른 Streaming Center 버전에도 설치되지만, 입력 감지 방식이 달라질 수 있습니다.

권리 안내
AVerMedia가 공급하거나 승인한 제품이 아닌 독립 플러그인입니다. 제조사 프로그램·DLL은 포함하지 않으며,
사용자 PC에 설치된 Streaming Center의 기능을 실행 중에만 사용합니다.
