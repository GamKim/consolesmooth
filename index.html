화질: 같은 입력, 실제 60fps와 비교

스위치 2 젤다(밤 숲) 화면을 실제 60fps로 무손실 녹화한 뒤, 짝수 장만 30fps 입력으로 넣고 각 프로그램이 만든 홀수 장을 실제 홀수 장과 비교했습니다(701장). 각 프로그램의 기본 설정 그대로이며, Veyra는 가장 높은 화질로 내보낸 파일입니다. 높을수록 실제 화면에 가깝습니다.

알아 둘 점

  • 빠른 저지연 방식은 저지연 보기 + 전체 화면 + 2배에서 쓰입니다. 모델이나 화면 설정을 바꾸면 Streaming Center를 다시 시작하세요(설정 창이 알려 줍니다).
  • 3배·4배, 목표 프레임, 30fps 보정, 안정 우선, 그래픽카드가 두 개인 노트북에서는 기존 방식(생성 버퍼 15~25ms)으로 동작합니다.
  • 빠른 방식이 안 되는 PC에서는 다음 시작부터 자동으로 기존 방식을 씁니다.
  • 저지연 보기를 켜 두면 녹화·방송에는 화면이 들어가지 않습니다. 생성 프레임을 녹화하려면 저지연 보기를 끄세요.
  • 측정 PC: NVIDIA GeForce RTX 5080, AVerMedia Live Gamer 4K GC573, 1920×1080, 2026년 11월 17~18일. 다른 그래픽카드에서는 결과가 다를 수 있습니다.
